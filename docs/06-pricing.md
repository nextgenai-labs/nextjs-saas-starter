## 1. Pricing Tiers

| Tier           | Price | License Type                                          | Best For                                      |
| -------------- | ----- | ----------------------------------------------------- | --------------------------------------------- |
| **Standard**   | $59   | Single-user, unlimited projects                       | Indie founders, freelancers                   |
| **Extended**   | $149  | Multi-user (up to 5 devs), unlimited projects         | Small agencies, startup teams                 |
| **Enterprise** | $499  | Unlimited users, priority support, white-label rights | Agencies, product teams, commercial resellers |

### One-time payment, not a subscription.

All tiers are one-time purchases. Buyers receive 12 months of updates included. After 12 months, they can purchase a 12-month update extension at 50% of the current tier price.

### Why one-time pricing?

- **Marketplace norms.** Codester and similar marketplaces are built around one-time payments. Subscriptions for boilerplate code are poorly received.
- **Lower friction.** A one-time $59 charge converts better than $9/month. Buyers rationalize it as a tool purchase, not an ongoing expense.
- **Higher perceived value.** A one-time price signals confidence in the product. Subscriptions signal ongoing dependency.

**Trade-off:** We trade recurring revenue for higher upfront conversion and marketplace suitability. The update extension (50% every 12 months) provides an ongoing revenue stream for existing customers.

## 2. License Details

### Standard License ($59)

- **Usage:** Use the source code in an unlimited number of personal or commercial projects
- **Team size:** 1 developer
- **Updates:** 12 months of minor and patch releases
- **Support:** Documentation, GitHub Issues (best-effort)
- **Resale:** You may not resell or redistribute the source code
- **Modification:** Unlimited — you can modify, extend, and rebrand

### Extended License ($149)

- **Usage:** Use the source code in an unlimited number of projects
- **Team size:** Up to 5 developers
- **Updates:** 12 months of minor and patch releases
- **Support:** Documentation, GitHub Issues (priority response)
- **Resale:** You may not resell or redistribute the source code
- **Modification:** Unlimited

### Enterprise License ($499)

- **Usage:** Use the source code in an unlimited number of projects
- **Team size:** Unlimited developers
- **Updates:** 12 months of minor and patch releases
- **Support:** Documentation, GitHub Issues, private email support
- **Resale:** White-label rights — can rebrand and redistribute as part of a larger service offering (e.g., you build client sites using the starter). You may not sell the starter in isolation.
- **Modification:** Unlimited
- **Additional:** Priority feature requests considered

### What No License Allows

- Redistributing the source code as a competing product on marketplaces
- Sub-licensing or reselling the starter in its original form
- Using the starter to build a product that is itself a "Next.js starter" or "SaaS boilerplate"

## 5. Payment & Delivery

- **Payment processors:** Stripe (direct) and marketplace checkout (Codester)
- **Direct purchase:** Buyers who purchase directly from our website receive the same license but we keep 100% of revenue (vs. ~70% on marketplaces).
- **Delivery:** ZIP file download via marketplace or email link. Includes full source code, README, and docs.
- **Refund policy:** 14-day money-back guarantee for direct purchases. Marketplace refunds follow marketplace policy.

### Refund Criteria

- Full refund if the product does not function as described and we cannot resolve the issue within 7 days.
- No refund if the buyer simply changes their mind or decides not to use the product.
- No refund after 14 days from purchase.
